# 한국어로 읽기

이 사이트의 주 언어는 영어다. 사건 카드의 위층, 사람이 읽어 내려가는 "읽는 글"만 한국어로 옮겨 여기에 둔다. 출처 번호·점수·등급 판정이 들어 있는 **조사 장부는 영어 카드에만** 있다. 두 벌을 두면 서로 어긋나기 때문이다. 사진·도해·출처·등급은 어느 언어에서도 같다.

등급 읽는 법: **R**(A–D)은 기록의 질이다. 출처·목격자·시점·평범한 설명 검토·조사자 독립성 다섯 축의 합계로, A는 당시 1차 기록에 복수 증인, D는 후대 전승이다. **V**(V2/V1/V0)는 당사자가 정상 경로로 알 수 없었던 정보가 담겼는가, 그리고 그것이 확인 전에 기록됐는가다. **I**(I2/I1/I0)는 다른 카드와의 접촉·번역·선교·매체·같은 조사자 다섯 경로가 전부 배제됐는가다. 규칙 전체는 [[METHOD]](영어), 연구 문장은 [[CHARTER]](영어), 모든 카드와 인물을 연대순으로 모은 표는 [[TIMELINE]](영어, 카드에서 자동 생성).
